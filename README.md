# Carta de cumpleaños para Tamara

Una carta web animada, adaptable a celulares y laptops, sin instalación.

- Abre `index.html` en Chrome, Edge, Firefox o el navegador del celular.
- Para abrir la carta, toca o haz clic en cualquier parte del sobre.
- El sobre se desvanece al abrirse para dejar la carta completamente despejada.
- El único control que aparece después es **Cerrar carta**, para volver al sobre y abrirla otra vez.
- Para cambiar el mensaje antes de compartirla, edita únicamente `mensaje.js` con el Bloc de notas. La persona que reciba la carta no verá un editor.
- El tamaño del texto se ajusta automáticamente para intentar mantenerlo dentro de la tarjeta.

Mantén juntos `index.html`, `styles.css`, `script.js` y `mensaje.js`.
